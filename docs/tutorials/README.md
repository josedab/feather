# Feather Tutorials

Step-by-step guides to get you productive with Feather, from first install to production deployment.

| # | Tutorial | Time | Description |
|---|----------|------|-------------|
| 1 | [Getting Started](01-getting-started.md) | 5 min | Install Feather, store and retrieve your first features |
| 2 | [Real-Time Fraud Detection](02-fraud-detection.md) | 15 min | Build a fraud detection feature pipeline with drift monitoring |
| 3 | [Migrating from Feast](03-migrating-from-feast.md) | 15 min | Move from Feast to Feather using the compatibility API |
| 4 | [Managing LLM Features](04-llm-features.md) | 15 min | Version prompts, cache responses, and store embeddings |
| 5 | [Deploying on Kubernetes](05-kubernetes-deployment.md) | 20 min | Production deployment with health checks, monitoring, and autoscaling |

## Prerequisites

All tutorials assume you have:
- **Go 1.24+** installed ([download](https://go.dev/dl/))
- **curl** available in your terminal
- **git** for cloning the repository

Individual tutorials list additional requirements at the top.

## Convention

Throughout these tutorials:
- Commands prefixed with `$` should be run in your terminal
- Expected output is shown in fenced blocks labeled `output`
- Placeholder values like `<your-value>` should be replaced with your own data
