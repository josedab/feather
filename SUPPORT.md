# Support

Thanks for using Feather! Here's how to get help.

## 🔍 Before Asking

1. **Check the [README](README.md)** — covers quick start, configuration, and API overview
2. **Search [existing issues](https://github.com/feather-store/feather/issues)** — your question may already be answered
3. **Read the [docs](docs/)** — architecture, API reference, package guide, and ADRs

## 💬 Community Channels

| Channel | Purpose |
|---------|---------|
| [GitHub Discussions](https://github.com/feather-store/feather/discussions) | Questions, ideas, show & tell |
| [Discord](https://discord.gg/feather-store) | Real-time chat, help, and community |
| [GitHub Issues](https://github.com/feather-store/feather/issues) | Bug reports and feature requests |

## 🐛 Reporting Bugs

Use the [bug report template](https://github.com/feather-store/feather/issues/new?template=bug_report.md) and include:

- Feather version (`feather --version`)
- Go version (`go version`)
- Operating system and architecture
- Steps to reproduce
- Expected vs actual behavior
- Relevant logs (with `FEATHER_LOG_LEVEL=debug`)

## 💡 Feature Requests

Use the [feature request template](https://github.com/feather-store/feather/issues/new?template=feature_request.md) and describe:

- The problem you're trying to solve
- Your proposed solution
- Alternatives you've considered

## 🔒 Security Issues

**Do not report security vulnerabilities through public issues.** See [SECURITY.md](SECURITY.md) for responsible disclosure instructions.
